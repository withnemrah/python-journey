# Calculator v2

A simple calculator written in Python. The user enters two numbers and an operation, and the program prints the result.

If the second number is 0 when dividing, the program prints "Undefined" instead of crashing. This is checked with an `if` condition.

## How to run

1. Open the project folder in VS Code.
2. Open `calculator.py`.
3. Click the Run button (or type `python calculator.py` in the terminal).

## How to use

1. Enter the first number and press Enter.
2. Enter the second number and press Enter.
3. Enter the operation: `+`, `-`, `*` or `/`, then press Enter.
4. The result is printed in the VS Code terminal.

Any other symbol prints "Invalid operation".
